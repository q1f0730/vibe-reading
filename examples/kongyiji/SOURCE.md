# 样本来源

- `kongyiji.txt`：鲁迅《孔乙己》（1919），公有领域。
  - 来源：维基文库 https://zh.wikisource.org/zh-hans/孔乙己 （底本《鲁迅全集》1938/1948 年本，页面简体转换），抓取于 2026-10-20。
  - 完整性核对：14 段（13 段正文 + 落款"（一九一九年三月。）"），共 2611 字；与同页繁体渲染逐段字数一致；首段"鲁镇的酒店的格局"、末段"大约孔乙己的确死了"均在；已去除零宽空格(U+200B)与页码标记。
  - 注意：保留底本用字（如"豫备""儍"），未改为现代规范字。引号为直角引号『』。
- 另一份内部测试文本（版权作品）不随仓库发布。
- `kongyiji.plan.json`：千问 qwen3.8-max 生成的分镜（质量模式）。`kongyiji.mercury.plan.json`：Mercury mercury-3（instant）生成的分镜（快速模式）。两者都可以用 `--plan` 直接渲染。
- `kongyiji.html`：用 `kongyiji.plan.json` 渲染的成品阅读页（单文件，可直接用浏览器打开）。
